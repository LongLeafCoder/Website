Private chat

Test the invitation, private conversations, group rooms, and wipe controls before we design a production system.

Encrypted-message prototype, not audited production chat. Each message body is encrypted for its sender and conversation members. Cloudflare KV stores the encrypted vault and wrapped keys; the Worker does not receive message plaintext. Remembered-device keys are stored in browser IndexedDB. The prototype’s KV write endpoint still needs production access controls, and a wipe cannot erase copies recipients already saved.
